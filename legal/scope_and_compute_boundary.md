# Scope and compute boundary

The available-memory gate is explicitly waived for this metadata-only phase. The preflight records measured available memory and the waiver; the waiver does not authorize MRI processing, imaging-volume access, GPU work, graph construction, model execution, or harmonization.

Only CSV, TSV, JSON, YAML, and text metadata are in scope. Input discovery is read-only and must stop on imaging volumes, unresolved source ambiguity, hash mismatch, or governance failure.
